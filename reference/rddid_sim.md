# Simulated RD-DID panel (running variable fixed over time)

A simulated panel in the setting of Leventer and Nevo: 1,000 units
observed in three years. A confounding policy `V` switches on above the
cutoff (`R >= 0`) in **every** year and raises the outcome by 0.5; the
treatment of interest `W` switches on above the cutoff only in year 3,
the RD period, and raises the outcome by 1. Years 1 and 2 are the
comparison periods (nobody is treated), so the jump in `Y` at the cutoff
there is the confounding jump alone. The target of
[`rddid()`](https://dorleventer.github.io/rddid/reference/rddid.md) is
the ATT in year 3, which is 1; a plain RD in year 3 would recover 1.5,
the effect plus the confounding jump.

## Usage

``` r
rddid_sim
```

## Format

A data frame with 3,000 rows (one per unit-year) and 6 columns:

- id:

  unit identifier, 1 to 1000.

- year:

  1, 2 (the comparison periods) or 3 (the RD period).

- R:

  running variable, uniform on \[-1, 1\]; the cutoff is 0.

- V:

  confounding policy, 1 if `R >= 0` (every year).

- W:

  treatment of interest, 1 if `R >= 0` and `year == 3`.

- Y:

  outcome.

## Source

Generated by `data-raw/make_sim.R` (seed 20261008). True effects:
confounding jump 0.5 in every year, treatment effect 1.

## Details

The running variable does not move between years, so every unit stays on
the same side of the cutoff (sampling scheme "panel, running variable
fixed over time"). The tests of the assumptions are degenerate here:
every unit keeps its type, so there is nothing to test (and
[`rd_typecont()`](https://dorleventer.github.io/rddid/reference/rd_typecont.md)
rejects mechanically); use
[rddid_sim_pv](https://dorleventer.github.io/rddid/reference/rddid_sim_pv.md)
for them.

## See also

[rddid_sim_pv](https://dorleventer.github.io/rddid/reference/rddid_sim_pv.md)
for the version with a moving running variable.

## Examples

``` r
head(rddid_sim)
#>   id year          R V W           Y
#> 1  1    1 -0.7785626 0 0 -0.38918276
#> 2  2    1 -0.9019249 0 0 -0.75738418
#> 3  3    1  0.1621249 1 0  1.10233495
#> 4  4    1  0.1695525 1 0  1.50736287
#> 5  5    1 -0.7321141 0 0 -0.04729411
#> 6  6    1  0.8406841 1 0  1.59100391
rddid(rddid_sim, y = "Y", x = "R", time = "year", id = "id", t_rd = 3)
#> RD-DID estimate of the ATT in period 3
#>   Comparison periods: 1, 2   (constant confounding trend; weights 0.5, 0.5)
#>   Sampling scheme: panel, running variable fixed over time: no unit changes side of the cutoff (detected from the data)
#>   Bandwidth: common h = 0.2672 (rule "joint", AMSE-optimal for the aggregate)
#>   Pilot bandwidth b (period = value): 1 = 0.4102, 2 = 0.3868, 3 = 0.3951
#> 
#>                              Estimate  Std. err.       z  p-value   95% CI
#>   Conventional                 1.0927     0.1264    8.64   <0.001   [0.8450, 1.3405]
#>   Robust (bias-corrected)      1.1414     0.1494    7.64   <0.001   [0.8486, 1.4342]
#> 
#>   summary() shows the per-period fits and the s.e. under every sampling scheme.
```
